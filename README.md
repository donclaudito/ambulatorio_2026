# Surgical Report Pro (Ambulatório 2026)

Gerador Inteligente de Laudos de Cirurgia Eletiva.

## Tecnologias
- React 19
- Vite
- Tailwind CSS
- Google Gemini AI API

## Funcionalidades
- Geração automatizada de anamnese e exame físico via IA.
- Mapeamento inteligente de comorbidades e medicamentos.
- Módulo de Laudo Final editável com integração de área de transferência.
- Impressão profissional formatada para prontuários médicos.
- Geração automática de solicitações de avaliação pré-operatória.
